# Philemon Kusi - Portfolio

Welcome to my professional portfolio. I'm a UI/UX & Graphic Designer dedicated to crafting effortless digital experiences.

## 🚀 Overview

This portfolio showcases selected works ranging from Fintech solutions to platform ecosystems for creators. It's built with modern technologies to ensure performance and a seamless user experience.

## 🛠️ Built With

- **React 18** - UI Library
- **Vite** - Build Tool
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **Lucide React** - Iconography
- **TypeScript** - Language

## ✨ Key Features

- **Project Filtering**: Browse projects by categories (Fintech, UI/UX, Marketplace, etc.)
- **Interactive Case Studies**: Detailed deep-dives into problems, solutions, and outcomes.
- **Micro-animations**: Subtle interactions that enhance the experience without distraction.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewports.

## 📁 Structure

- `src/components/`: Reusable UI modules (Hero, ProjectCard, Navbar, etc.)
- `src/pages/`: Main application views (Home, ProjectDetail)
- `src/constants.ts`: Centralized data management for projects and skills.
